About ProphetAI

Full-Stack Machine Learning Web Platform for Intelligent Real Estate Valuation.

Project Objective

ProphetAI provides precision house price forecasting using state-of-the-art machine learning algorithms trained on comprehensive Indian real estate market parameters. The system automatically calculates target metrics: House Price, Price_in_Lakhs, and Price_per_SqFt.

Full Stack Technology Architecture

Front-End

  • HTML5 & Modern Semantic Layouts
  • Vanilla CSS3 Dark Glassmorphism
  • Vanilla ES6 JavaScript Engine
  • Chart.js Analytics Visualizations

Back-End Framework

  • Python 3.11 Runtime
  • Flask Web Application Framework
  • Werkzeug Password Security
  • SQLite User Database

Machine Learning

  • Scikit-Learn (Linear Regression, DT, RF)
  • XGBoost Regressor v3.2
  • StandardScaler & LabelEncoder Pipeline
  • Joblib Artifact Serialization

Machine Learning Regressors Explained

1. Linear Regression

Models property value using linear combinations of input features. Evaluates coefficients to determine direct feature impact.

2. Decision Tree Regressor

Constructs decision split rules across spatial attributes (City, Locality, BHK, Size) to capture localized price variance.

3. Random Forest Regressor

Ensemble bagging architecture combining hundreds of decision trees with feature bootstrapping for high robustness and minimal overfitting.

4. XGBoost Regressor

Optimized gradient boosting framework that minimizes residual errors iteratively, yielding top predictive performance on real estate tabular datasets.
